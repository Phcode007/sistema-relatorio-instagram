## 🎯 Sobre o Projeto

Sistema web completo para gestão de relatórios semanais do Instagram, desenvolvido para **Iandra Jamille - Auxiliar de Marketing** da empresa **Material para Construção - Nossa Senhora da Conceição**.

### ✨ Funcionalidades Principais

- 📈 **Atendimento**: Controle de mensagens, respostas, reservas e orçamentos
- 📱 **Conteúdo**: Análise de Stories, Reels, visualizações e engajamento
- 📊 **Dashboard**: Estatísticas em tempo real e resumos automáticos
- 💾 **Persistência**: Salvamento automático no navegador (localStorage)
- 📄 **Relatórios**: Geração e impressão de relatórios completos
- 📲 **Responsivo**: Totalmente otimizado para mobile, tablet e desktop
